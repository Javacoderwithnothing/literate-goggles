Link your Minecraft account

After signing in, players will be able to link their Minecraft account by proving they control it in-game.

  1. Sign in to your website account.
  2. Request a temporary verification code.
  3. Join the server and enter the code in-game.
  4. The server verifies the link and updates your profile.
Security note: the final system needs a backend and a Minecraft plugin. A username-only form is not proof of account ownership.
